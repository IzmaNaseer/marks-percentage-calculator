# Marks Percentage Calculator

A basic beginner project built using HTML, CSS, and JavaScript.
Live Demo: View My Calculator
https://izmanaseer.github.io/marks-percentage-calculator/

## Features
- Calculates marks percentage.
- Takes obtained marks and total marks as input.
- Displays the calculated percentage.

## How to Use
1. Enter your obtained marks.
2. Enter the total marks.
3. Click the Calculate button to see your percentage.

## Technologies Used
- HTML
- CSS
- JavaScript
